# Assignment 3: Fox Spirit Grove

First-person WebGL world for CSE 160 Assignment 3.

Live page:
https://jejcueva.github.io/CSE-160/asgn3/

Controls:
- W/A/S/D: move around the world
- Q/E: rotate left and right
- Drag on the canvas: mouse look
- F: remove the block stack in front of the camera
- G: add to the block stack in front of the camera

Rubric coverage:
- 32x32 hardcoded voxel height map
- Flattened cube ground and large cube sky
- Multiple local textures: grass, stone, wood, and sky
- Perspective camera with keyboard and mouse controls
- Add/delete block interaction
- Assignment 2 fox model placed in the world
- Simple story: recover three spirit flames and return to the shrine
