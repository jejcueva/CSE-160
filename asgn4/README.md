# Assignment 4: Lit Fox Spirit Grove

First-person WebGL world for CSE 160 Assignment 4.

Live page:
https://jejcueva.github.io/CSE-160/asgn4/

Controls:
- W/A/S/D: move around the world
- Q/E: rotate left and right
- Drag on the canvas: mouse look
- F: remove the block stack in front of the camera
- G: add to the block stack in front of the camera
- Lighting, normal visualization, point light, and spotlight buttons: toggle each lighting mode
- Light X/Y/Z sliders: move the animated point light path
- Red/Green/Blue sliders: change the point light color

Rubric coverage:
- Sphere primitive with normals
- Ambient, diffuse, and specular Phong lighting
- Point light marker, animated point light, and slider-controlled offset/color
- Button toggles for lighting and normal visualization
- Independent spotlight toggle
- Local OBJ model loaded from `assets/models/spirit-lantern.obj`
- Assignment 3 world and Assignment 2 fox integrated into the lighting scene
